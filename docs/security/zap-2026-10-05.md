## Caveats

- Local database, development configuration (`RATE_LIMIT_SCALE=20`); production uses the normal
  limits. With them, an active scan is throttled to a trickle by design; run it against staging
  with a raised scale or from an allowlisted address.
- The active scan authenticates as nobody: the signed-in routes are covered by the generated
  tenant-isolation tests (Day 18/60), not by ZAP. A scan with a session cookie is a launch-week
  follow-up.
- Not run: the extension (not a web target) and the storage host (MinIO, not ours).
