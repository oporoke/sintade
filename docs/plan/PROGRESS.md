Take metadata (start time, duration) for the recovery dialog comes with Day 26's `listOrphans()`. **Found on CI:** WebKit aborted the IndexedDB write with a `null` error. WebKit refuses to store `Blob`s in IndexedDB in ephemeral/private contexts, which Playwright contexts are, and real Safari private windows would hit the same. Records now store an `ArrayBuffer` plus the MIME type (works in every engine), and transaction failures carry a real error. Final CI: e2e 34 passed (both backends on all three engines), 2 skipped |
