## Known issues / open items

- MinIO's official free Docker images moved from Docker Hub to `quay.io/minio/*` (Oct 2025 policy change); `docs/design.md`'s "MinIO bucket CORS" line doesn't apply to the free/community edition (per-bucket CORS is AIStor/paid-only) — CORS is configured server-wide via `MINIO_API_CORS_ALLOW_ORIGIN` instead, which is equivalent for a single-bucket dev setup.
- This sandbox's network cannot download Playwright's own Firefox/WebKit browser binaries: `npx playwright install` (with or without `--with-deps`) stalls indefinitely on the actual binary download (HEAD requests to the CDN succeed in ~3s; GET of the ~100–300MB archives transfers 0 bytes over 30s+ and the process silently restarts). `--with-deps` also can't run at all here (needs interactive `sudo`). Worked around for Day 9 by pointing the `chromium` Playwright project at the system-installed Google Chrome via `channel: 'chrome'` (real CDP automation, not a stub) — genuinely verified. The `firefox`/`webkit` projects are configured in `web/playwright.config.ts` but commented out, since Playwright has no equivalent "use the system browser" path for those engines (it needs its own patched builds). Needs a real network (e.g. Day 10's CI) to fully verify.
